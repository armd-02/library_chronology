# 図書館年表マップ

日本の図書館の歴史を、地図と年表からたどるウェブサイトです。[Community Map Maker](https://github.com/K-Sakanoshita/community_mapmaker/tree/46e3785c391034b9241f7eeeea8d2f036b0ffd06) をベースにしています。

[図書館年表マップを開く](https://armd-02.github.io/library_chronology/)

## 使い方

- 地図のアイコンをタップすると、施設の情報と、その施設にひも付く年表の記録を表示します。カテゴリとキーワードで年表を絞り込めます。
- 年表上部のスライダーで一覧の位置を移動できます。再生中は、現在の行を黄色で強調し、機関や地域の情報を展開します。地図では対応する施設のアイコンを金色の輪で示します。年表を移動しても、表示中のズームを維持します。
- ▶で選んだ位置から再生し、■で停止します。速度ボタンを押すたびに ×1、×2、×4、×8、×0.5 の順で切り替わります。詳細パネルでは、同じ操作バーで開いている施設の記録だけを移動・再生できます。
- 年表データの取得中は地図左下にスピナーを表示します。

## 更新履歴

### 2026年11月19日 — 年表の再生と地図操作を改善

- 再生・停止と速度の操作を年表上部に移し、年表だけが独立してスクロールするようにしました。
- スライダーを年表のスクロール位置と連動させ、選んだ位置から再生できるようにしました。再生速度は ×1、×2、×4、×8、×0.5 の5段階にしました。
- 再生やスライダー操作で選んだ行を黄色で強調し、機関と地域を行内で表示するようにしました。地図では対応する施設のアイコンを金色の輪で強調します。
- 年表は対象行へ滑らかにスクロールし、地図は現在のズームのまま対象地点へ移動するようにしました。
- 施設の詳細パネルにも同じ操作バーを設け、その施設の記録だけを移動・再生できるようにしました。詳細を閉じると、全国の年表の元の位置に戻ります。
- 地図の最小ズームと、年表の記録がある施設の表示開始ズームを5から3に変更しました。地図の中心は離島を含む東経120〜157度・北緯19〜48度に制限しました。
- 縦並びのサイドバーの通常時の高さを画面の35%から50%に変更しました。
- 地図を動かしても年表の内容が変わらないときは、一覧の再確認を省き、地図のアイコンだけを更新するようにしました。
- バックエンドから年表を取得している間、地図左下にスピナーを表示するようにしました。通信が重なったときは、最後の通信が終わるまで表示します。 [年表・地図操作の改善](https://github.com/armd-02/library_chronology/commit/585bd00)

### 2026年11月19日 — 閲覧機能を整理

- 詳細パネルと一覧の「訪問済み」「お気に入り」をオフにしました。 [訪問済み](https://github.com/armd-02/library_chronology/commit/fd6d58d) · [お気に入り](https://github.com/armd-02/library_chronology/commit/ade92f3)

### 2026年11月19日 — Community Map Makerへ移行

- 旧サイトをCommunity Map Makerへ移行しました。カテゴリ・キーワードによる絞り込み、年表の連続再生、施設ごとの詳細表示を引き継ぎました。
- 年表の取得先をGoogle Apps ScriptからCommunity Map Makerのバックエンドに切り替え、5,504件の記録を移行しました。年月日順に並べ、月や日が不明な記録もそのまま扱えるようにしました。
- OpenStreetMapの図書館情報をOverpassで更新し、国立国会図書館のISIL管理台帳と照合しました。地図上で確認できた公共図書館を補い、施設の重複を整理しました。
- OSM IDが変わった施設は旧リンクからも表示できるようにしました。石川県立図書館の旧館は移転前の位置を保持し、寒川文書館と国立文化財機構の記録はそれぞれ寒川総合図書館と東京国立博物館の位置にひも付けました。
- OSMFJのベクトル地図をもとに旧サイトのダーク配色を再現しました。道路番号の表示を控えめにし、建物を非表示にしました。
- 起動画面とSNS共有用画像を図書館年表マップのイラストに差し替え、一覧とメニューに巻物と本の背景を設定しました。 [移行時の変更](https://github.com/armd-02/library_chronology/commit/e43735d)
